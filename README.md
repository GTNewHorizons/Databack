## Datapack

Datapack backport for Minecraft 1.7.10. This project's primary goal is to backport worldgen datapacks, so other resource types will be ignored. Contributions for extending support are welcome.

This project's DTOs were created through the use of AI. An LLM was used to convert [mcdoc](https://github.com/SpyglassMC/vanilla-mcdoc/) to typescript types, and another LLM was used to generate DTOs for those types. Most of the logic (e.g. for density functions) is trivial and obvious, but some of it isn't. In these situations, the logic is hand-done, but that's rare. The important logic was hand-written. The [GTNH AI Policy](https://github.com/GTNewHorizons/GTNH-Dev-Doc/blob/master/AI_POLICY.md) must still be followed.
